什么会进待审

插件只提供队列和收/扔，不决定什么时候投料；投料由使用者的 agent / CLI 决定。下面是常见判据。

  • 他明确说「记住 / 以后 / 别再 / 规矩」，但没指定放哪一层。
  • 一条结论以后用得上，但不确定该放 facts / self / voices 哪一层。
  • 我发现自己反复犯同一个错，还没想好该写成什么规则。

不投：事实性对话、天气、哪条视频好看、一次性情绪；已经有明确落点的；这次已经直接写进某层的。

来源必填（--src）；收/扔由人决定。插件不投料，也没有默认定时任务。
